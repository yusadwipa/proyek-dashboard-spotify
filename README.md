# Dashboard Top Spotify Songs 2023

> Visualisasi interaktif mengenai jumlah streams, metrik danceability, dan tempo (BPM) dari lagu-lagu hits global tahun 2023 berdasarkan data Spotify.

🌐 **Demo:** [https://proyek-dashboard-spotify.vercel.app/]

## Isi Dashboard
- **Chart 1:** Bar Chart — Menampilkan perbandingan total pemutaran (streams) dalam skala jutaan dari 10 lagu populer.
- **Chart 2:** Doughnut Chart — Menunjukkan proporsi skor *danceability* (kesesuaian lagu untuk menari) dari setiap track.
- **Kartu Sorotan:** Menampilkan rangkuman data penting (Paling banyak diputar, paling asik untuk menari, dan rata-rata tempo).
- **Chart 3:** Line Chart — Menampilkan tren tempo (BPM/Beats Per Minute) antar lagu untuk melihat pola kecepatan ritme musik hits.
- **Fitur interaktif:** *Tooltip* yang akan menampilkan data spesifik saat kursor berada di atas elemen *chart*, dan *legend toggle* untuk menyembunyikan/menampilkan metrik.
- **Animasi:** Animasi *entrance* bawaan Chart.js yang berjalan halus saat halaman pertama kali di-load.

## Sumber Data
- **Nama dataset:** Top Spotify Songs 2023 (Kaggle)
- **URL sumber:** https://www.kaggle.com/datasets/nelgiriyewithana/top-spotify-songs-2023
